# Zerde 109 AI Intelligence Core (Python)

Высокопроизводительное интеллектуальное AI/ML ядро для аналитики и маршрутизации обращений граждан в службу 109 (Казахстан).

---

## 1. Возможности платформы

- **Смарт-приём и классификация (`Module 1`)**:
  - Двуязычная обработка (казахский и русский языки) в реальном времени.
  - Высокоскоростной CPU-пайплайн: **TurkicNLP** (лемматизация и морфология казахского языка) + **Natasha** (русский язык, NER, синтаксис).
  - Извлечение сущностей: адреса (улицы, номера домов), объекты инфраструктуры, описание инцидента.
  - Определение приоритета: автоматическое повышение до `high` при обнаружении аварийных маркеров («су ағып жатыр», «порыв трубы», «нет тепла», «ледяные батареи»).
  - Защита от галлюцинаций: **ZerdeVerifier** на основе энтропии Шеннона и семантической когерентности.
  - Fallback на локальную LLM (**KazLLM 8B / Qwen 2.5 7B** через Ollama на GPU RTX 4070).

- **Ассистент оператора (`Module 2`)**:
  - Семантический векторный поиск похожих исторических инцидентов (`ZerdeVectorStore` на базе `SentenceTransformers`).
  - Мгновенная детекция дубликатов обращений (threshold косинусной близости 0.82).
  - Шаблоны ответов гражданам на казахском и русском языках с автоматической подстановкой регламентных сроков.

- **Ситуационный центр руководителя (`Module 3`)**:
  - Аналитическое хранилище на 143 792 реальных обращений из 7 регионов (`data/unified_appeals.parquet`).
  - **SpikeDetector**: статистический Z-score детектор аномалий и всплесков коммунальных аварий.
  - **WorkloadForecaster**: планирование штатной численности операторов по формуле **Erlang-C**.
  - **ExecutiveNLQueryEngine**: ответы на естественные вопросы руководства на казахском и русском языках.
  - Экспорт аналитических отчетов в CSV.

## 2. Структура каталога `ai/`

```
ai/
├── src/
│   ├── analytics/           # SpikeDetector, WorkloadForecaster, NLQueryEngine
│   ├── api/                 # FastAPI приложение, схемы и frontend_bridge.py
│   ├── config/              # Pydantic v2 Settings (settings.py)
│   ├── data/                # Словари терминов и маппинг 17 категорий 109
│   ├── evaluation/          # Скрипты оценки качества и бенчмарки F1
│   ├── graph/               # Клиент Neo4j с автоматическим fallback
│   ├── pipeline/            # TurkicNLP, Natasha, LanguageDetector, Verifier, Classifier
│   └── vector_store/        # Векторная база обращений и детекция дубликатов
├── data/
│   ├── unified_appeals.parquet # 143k верифицированных обращений
│   └── evaluation_report.json  # Результаты бэктеста модели
├── tests/                   # 37 юнит- и интеграционных тестов (pytest)
├── requirements.txt         # Зависимости Python (FastAPI, PyTorch, Natasha, etc.)
└── .env.example             # Пример переменных окружения
```

## 3. Установка и запуск

### Требования
- **Python 3.11+**
- (Опционально) Ollama с моделью `kazllm-8b` или `qwen2.5:7b` для GPU-ускоренного LLM fallback.

### Установка зависимостей
```bash
cd ai
python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### Запуск FastAPI сервера
```bash
python -m uvicorn src.api.api:app --host 127.0.0.1 --port 8000 --reload
```
API документация Swagger UI доступна по адресу: **http://127.0.0.1:8000/docs**

## 4. Тестирование

```bash
# Запуск полного набора тестов ядра и интеграции с фронтендом
pytest tests/ -v
```
Все 37 тестов (NLP-пайплайн, детекция аномалий, прогнозирование Erlang-C, NL Query, и 16 эндпоинтов `@zerde/web`) выполняются за ~35 секунд.
